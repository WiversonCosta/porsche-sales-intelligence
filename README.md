# Porsche Sales Intelligence

Dashboard interativa desenvolvida a partir de uma base de 100 vendas de veículos Porsche. O projeto permite analisar desempenho comercial por modelo, ano-modelo, cidade, forma de pagamento e período.

## Dashboard publicada

https://porsche-sales-intelligence.wiversoncosta.chatgpt.site/

## Principais recursos

- filtros por modelo Porsche, ano-modelo, cidade, forma de pagamento e período;
- indicadores de vendas, receita, ticket médio e ano-modelo líder;
- ranking dos modelos mais vendidos e cidades em destaque;
- análise de saída por ano-modelo;
- insights executivos atualizados conforme os filtros;
- tabela de popularidade local com modelo, ticket médio e pagamento preferido por cidade;
- layout responsivo inspirado na linguagem visual elegante e minimalista da Porsche.

## Tecnologias

- Next.js;
- React;
- TypeScript;
- CSS responsivo;
- dados consolidados em TypeScript.

## Como executar

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:3000` no navegador.

## Observação sobre os dados

A base possui 100 transações. Destas, 76 têm datas validadas para o filtro de período. Sem período selecionado, todos os registros são considerados nos indicadores.

## Objetivo acadêmico

Projeto desenvolvido para aplicar análise de dados, construção de KPIs, visualização de informações e criação de dashboards com apoio de agentes de IA.
